Title: Find Target Indices After Sorting Array
URL: https://leetcode.com/problems/find-target-indices-after-sorting-array/

LLM Explanation:
Count elements less than target (= start index) and equal to target (= run length). Return that range. O(n) time, O(1) space.

LLM Testcase Validation:
Test 1: target=2. less=1(only 1<2), count=2. → [1,2] ✓
Test 2: target=3. less=3(1,2,2<3), count=1. → [3] ✓
Test 3: target=5. less=4(1,2,2,3<5), count=1. → [4] ✓
