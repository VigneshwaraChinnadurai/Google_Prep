Title: Count Nodes Equal to Average of Subtree
URL: https://leetcode.com/problems/count-nodes-equal-to-average-of-subtree/

LLM Explanation:
APPROACH: Post-order DFS returning (subtree_sum, subtree_count) — O(n).

Each dfs call returns the sum and node count of the subtree rooted at the current node.
At each node, compute the integer average (floor division) and compare to node.val.
Increment counter on match.

COMPLEXITY: O(n) time, O(h) space for recursion stack where h is tree height.

EDGE CASES:
  Single node: subtree is itself, average = node.val → always counts.
  Node.val = 0: 0 // 1 = 0 ✓ handled correctly.
  Large subtrees: integer overflow not possible in Python.

LLM Testcase Validation:
Test 1: root=[4,8,5,0,1,null,6]
Tree:        4
           /   \
          8     5
         / \     \
        0   1     6

dfs(0): sum=0,cnt=1. 0//1=0==0 ✓ count=1. return (0,1)
dfs(1): sum=1,cnt=1. 1//1=1==1 ✓ count=2. return (1,1)
dfs(8): sum=0+1+8=9,cnt=3. 9//3=3≠8. return (9,3)
dfs(6): sum=6,cnt=1. 6//1=6==6 ✓ count=3. return (6,1)
dfs(5): sum=6+5=11,cnt=2. 11//2=5==5 ✓ count=4. return (11,2)
dfs(4): sum=9+11+4=24,cnt=6. 24//6=4==4 ✓ count=5. return (24,6)
Return 5 ✓

Test 2: root=[1]
dfs(1): sum=1,cnt=1. 1//1=1==1 ✓ count=1. return (1,1)
