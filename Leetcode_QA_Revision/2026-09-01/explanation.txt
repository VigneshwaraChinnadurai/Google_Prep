Title: Minimum Moves to Clean the Classroom
URL: https://leetcode.com/problems/minimum-moves-to-clean-the-classroom/

LLM Explanation:
APPROACH: BFS on state (row, col, litter_mask, energy_remaining).

STATE SPACE:
  Position: m×n ≤ 400 cells
  Litter mask: 2^10 = 1024 (at most 10 litter cells)
  Energy: 1..50 levels
  Total states: 400 × 1024 × 50 = ~20M — feasible.

BFS guarantees minimum moves since each step costs 1.

KEY MECHANICS:
  - Energy decreases by 1 per move. If e=0, can't move (e<=0 check before moving).
  - Landing on 'R' resets energy to full capacity.
  - Landing on 'L' sets the corresponding bit in litter_mask.
  - 'X' cells are impassable.
  - When litter_mask reaches full_mask, return current move count + 1.

VISITED ARRAY: 4D boolean array [r][c][mask][energy] prevents re-exploring
identical states, ensuring termination and correctness.

COMPLEXITY:
  Time:  O(m × n × 2^L × E) where L ≤ 10, E ≤ 50
  Space: O(m × n × 2^L × E) for visited array

EDGE CASES:
  No litter: return 0 immediately.
  Starting on litter: initial mask includes that litter bit.
  Energy exhausted far from R: state becomes dead (e=0, not on R).
  Disconnected litter behind obstacles: BFS naturally returns -1.

LLM Testcase Validation:

start=(0,0), litter=[(1,1)], full_mask=1
BFS: (0,0,0,2)→right→(0,1,0,1)→down→(1,1,1,0). mask==full_mask. Return 2 ✓
