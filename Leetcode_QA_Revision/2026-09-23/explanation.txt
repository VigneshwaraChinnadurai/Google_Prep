Title: Minimum Operations to Reduce X to Zero
URL: https://leetcode.com/problems/minimum-operations-to-reduce-x-to-zero/

LLM Explanation:
APPROACH: Sliding window on the complement — O(n).

Removing a prefix and suffix with total sum x is equivalent to keeping a contiguous
subarray with sum = total_sum - x. We want to MAXIMIZE the length of this kept
subarray (to MINIMIZE the number of removed elements = operations).

Use a sliding window to find the longest subarray with sum == target = sum(nums) - x.
Answer = n - max_len.

EDGE CASES:
  target < 0: impossible (x > sum), return -1.
  target == 0: keep no elements, all n ops needed → return n.
  No subarray found: max_len stays -1, return -1.

COMPLEXITY: O(n) time, O(1) space. Valid since all nums[i] >= 1 (no negatives),
so the sliding window shrink is monotone.
