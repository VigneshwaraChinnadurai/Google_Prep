Title: Maximum K to Sort a Permutation
URL: https://leetcode.com/problems/maximum-k-to-sort-a-permutation/

LLM Explanation:
Every misplaced element has to be swapped at least once, so any swap it takes part in must satisfy nums[i] & nums[j] == k. That means k must be a submask of every misplaced value. The largest such k is the AND of all misplaced values.

This k is also achievable: the AND of the misplaced values is the maximum candidate, and the swap graph it induces is enough to sort the array. This is the accepted solution for this problem, though I did not prove connectivity of the swap graph here.

Algorithm:
- Start with ans = -1 (all bits set).
- For each index i where nums[i] != i, do ans &= nums[i].
- If no element was misplaced, ans is still -1, so return 0.

Time complexity: O(n). Space complexity: O(1).

Edge cases:
- Already sorted array, including n=1, returns 0.
- Value 0 is never misplaced unless the array is unsorted. If it is, ans becomes 0.
- If the only misplaced elements are two values like 3 and 2, the answer is their AND (2).

LLM Testcase Validation:
[0,3,2,1] -> misplaced values are 3 (index 1) and 1 (index 3). 3 & 1 = 1. Expected 1. PASS
[0,1,3,2] -> misplaced values are 3 (index 2) and 2 (index 3). 3 & 2 = 2. Expected 2. PASS
[3,2,1,0] -> every element is misplaced. 3 & 2 & 1 & 0 = 0. Expected 0. PASS
