Title: Rectangle Overlap
URL: https://leetcode.com/problems/rectangle-overlap/

LLM Explanation:
Two rectangles overlap (positive intersection area) iff they overlap on BOTH axes.
On x-axis: rec1.x1 < rec2.x2 AND rec2.x1 < rec1.x2 (strict — touching doesn't count).
On y-axis: rec1.y1 < rec2.y2 AND rec2.y1 < rec1.y2 (strict).
O(1) time and space.

LLM Testcase Validation:
Test 1: rec1=[0,0,2,2], rec2=[1,1,3,3]
0<3✓ 1<2✓ 0<3✓ 1<2✓ → True ✓

Test 2: rec1=[0,0,1,1], rec2=[1,0,2,1]
0<2✓ 1<1? No → False ✓

Test 3: rec1=[0,0,1,1], rec2=[2,2,3,3]
0<3✓ 2<1? No → False ✓
