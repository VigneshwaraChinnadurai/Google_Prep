Title: Product of the Last K Numbers
URL: https://leetcode.com/problems/product-of-the-last-k-numbers/

LLM Explanation:
Keep a list of prefix products over the numbers added since the most recent zero, starting with a sentinel 1. Adding a nonzero number appends the previous prefix times that number. Adding a zero makes every product that includes it equal to 0, so the list is reset to [1].

For getProduct(k), the list holds one entry per nonzero number since the last zero, plus the sentinel. If k is at least the list length, the last k numbers include the zero, so the answer is 0. Otherwise the product of the last k numbers is pref[-1] divided by pref[-1-k]. Because every kept number is nonzero, the division is exact.

Time complexity: O(1) per add and per getProduct, which meets the follow-up. Space complexity: O(n) for the prefix list.

Edge cases:
- A zero as the most recent number gives pref=[1], so any k >= 1 returns 0.
- k equal to the number of nonzero entries since the last zero uses the sentinel pref[0]=1 and returns the full product.
- Numbers equal to 1 keep the prefix unchanged, and the integer division stays exact.
- Products fit in 32 bits by the constraints, and Python integers do not overflow anyway.

LLM Testcase Validation:
add(3): pref=[1,3]. add(0): the zero resets pref to [1]. add(2): pref=[1,2]. add(5): pref=[1,2,10]. add(4): pref=[1,2,10,40].
getProduct(2): len(pref)=4, k=2 < 4, so 40 // pref[-3] = 40 // 2 = 20. Expected 20. PASS
getProduct(3): k=3 < 4, so 40 // pref[-4] = 40 // 1 = 40. Expected 40. PASS
getProduct(4): k=4 >= len(pref)=4, so the window reaches back to the zero and the result is 0. Expected 0. PASS
add(8): pref=[1,2,10,40,320]. getProduct(2): 320 // pref[-3] = 320 // 10 = 32. Expected 32. PASS
