Title: Maximum Alternating Sum of Squares
URL: https://leetcode.com/problems/maximum-alternating-sum-of-squares/

LLM Explanation:
KEY INSIGHT: Squaring removes sign, so we work with absolute values. We can freely
rearrange, so we optimally assign:
- The ceil(n/2) largest absolute values to POSITIVE (+) positions (even indices).
- The floor(n/2) smallest absolute values to NEGATIVE (-) positions (odd indices).

This maximises the positive sum and minimises the negative sum simultaneously.

COMPLEXITY: O(n log n) for sorting, O(n) for summation. Total O(n log n).

EDGE CASES:
  n=1: only one + position, no - positions. Result = nums[0]².
  All same values: pairs cancel except the last + position.
  Negative numbers: absolute values used since x² = (-x)².
