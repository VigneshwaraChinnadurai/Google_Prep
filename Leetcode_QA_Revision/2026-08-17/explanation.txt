Title: Stone Game V
URL: https://leetcode.com/problems/stone-game-v/

LLM Explanation:
APPROACH: Interval DP with binary search + prefix/suffix range-max arrays to reduce O(n^3) to O(n^2 log n).

KEY INSIGHT:
For interval [l,r], as split point k increases from l to r-1:
  - left_sum  = prefix[k+1] - prefix[l]  (strictly increasing)
  - right_sum = prefix[r+1] - prefix[k+1] (strictly decreasing)
There is a crossover kstar = smallest k where left_sum >= right_sum.

For k < kstar  (left < right): gain = left_sum  + dp[l][k]
                                     = (prefix[k+1] + dp[l][k]) - prefix[l]
For k > kstar  (left > right): gain = right_sum + dp[k+1][r]
                                     = prefix[r+1] + (dp[k+1][r] - prefix[k+1])
At kstar, if equal: gain = left_sum + max(dp[l][kstar], dp[kstar+1][r])

PRECOMPUTED RANGE MAXIMA (updated as we go):
  lp[l][k] = max over j in [l,k]   of (prefix[j+1] + dp[l][j])
  rs[l][r] = max over j in [l+1,r] of (dp[j][r]    - prefix[j])

LOOP ORDER: outer=length 2..n, inner=l decreasing (n-length..0).
Decreasing l ensures rs[l+1][r] is computed before rs[l][r] at the same length.

COMPLEXITY:
  Time:  O(n^2 log n) — n^2 states x O(log n) binary search
  Space: O(n^2)

EDGE CASES:
  n=1: return 0 immediately.
  Equal split: handled explicitly at kstar.
  kstar at boundary (l or r-1): boundary checks prevent out-of-range access.
