Title: Stone Game VIII
URL: https://leetcode.com/problems/stone-game-viii/

LLM Explanation:
APPROACH: Greedy DP with prefix sums — O(n) time.

KEY INSIGHT:
When a player removes the leftmost x stones (x > 1) and replaces them with
their sum S = stones[0]+...+stones[x-1] = prefix[x-1], the new row starts
with value prefix[x-1]. The next player then picks some y > 1 stones from
this new row, getting prefix[x-1] + stones[x] + ... + stones[x+y-2] = prefix[x+y-2].

So every move is characterised by choosing a "cut index" i (1-indexed prefix):
the current player scores prefix[i], and the new leftmost stone becomes prefix[i].
The next player must pick a cut index j > i.

Define dp[i] = best (current_player_score - opponent_score) when it's the current
player's turn and they must cut at some index in [i, n-1].

Base: dp[n-1] = prefix[n-1]  (forced move, opponent scores nothing more)

Transition (right to left): at index i, current player can:

  1. Cut here: gains prefix[i], then opponent plays from i+1 → opponent gets dp[i+1],
     so net = prefix[i] - dp[i+1]
  2. Skip to i+1: dp[i+1] (same player now chooses from i+1 onward)

dp[i] = max(prefix[i] - dp[i+1], dp[i+1])

Alice goes first and must pick i in [1, n-1]. Answer = dp[1].

This collapses to a single scalar updated right to left, giving O(n) time and O(1) space.

COMPLEXITY: O(n) time, O(1) extra space (prefix built in-place or as array O(n)).
EDGE CASES: n=2 → only one possible cut (index 1), Alice must take both stones.

LLM Testcase Validation:

prefix=[-1,1,-2,2,-3]

i=1: dp=max(prefix[1]-5, 5)=max(1-5,5)=max(-4,5)=5
Return 5 ✓
