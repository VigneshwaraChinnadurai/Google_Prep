Title: Find X Value of Array II
URL: https://leetcode.com/problems/find-x-value-of-array-ii/

LLM Explanation:
APPROACH: Segment tree with product-count merge — O((n + q) * k * log n).

SEGMENT TREE NODE: Each node covering range [l, r] stores:
  - prod: product(nums[l..r]) % k
  - cnt[k]: cnt[rem] = number of right endpoints j in [l,r] such that
    product(nums[l..j]) % k == rem.

MERGE (left [l,m] + right [m+1,r]):
  - prod = left.prod * right.prod % k
  - cnt[rem] = left.cnt[rem] for all rem (subarrays fully in left)
             + for each right.cnt[rem]: cnt[(left.prod * rem) % k] += right.cnt[rem]
             (subarrays starting at l extending into right: full left range product
              prepended to each right subarray)

KEY INSIGHT: product(l..j) for j in [m+1,r] = product(l..m) * product(m+1..j).
So the remainder of an extended subarray is (left.prod * right_rem) % k.

QUERY [start, n-1]: Use standard segment tree range query, maintaining left-to-right
order during merge. Result cnt[x] is the answer.

UPDATE: Point update at index, propagate up rebuilding cnt arrays.

COMPLEXITY:
  Build: O(n * k)
  Update: O(k * log n) per query
  Query: O(k * log n) per query
  Total: O((n + q) * k * log n) with k≤5, n≤10^5, q≤2*10^4 → ~10^7 ops.

EDGE CASES:
  Leaf nodes: cnt[nums[i]%k] = 1, prod = nums[i]%k.
  Empty ranges: handled by initializing with identity (prod=1, cnt=zeros).
  Positions beyond n in segment tree (padding to power of 2): leaves have prod=1,
  cnt=[0]*k, contributing nothing to products.
