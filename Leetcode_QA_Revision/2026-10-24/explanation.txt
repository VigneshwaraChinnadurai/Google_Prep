Title: Count Days Spent Together
URL: https://leetcode.com/problems/count-days-spent-together/

LLM Explanation:
Approach: convert each "MM-DD" date to its day of the year using prefix sums of the month lengths. Then the problem becomes the overlap of two closed integer intervals. The shared stay starts on the later arrival and ends on the earlier departure, so the answer is max(0, min(leaves) - max(arrivals) + 1).

Why it is correct: both stays are inclusive ranges in the same non-leap year. Day-of-year numbering preserves date order, so the intersection of the two ranges is exactly the set of shared days. If the intervals don't intersect, end < start and the max(0, ...) clamp returns 0.

Complexity: O(1) time and O(1) space, since the date strings and month table have fixed size.

Edge cases:
- Identical stays: the overlap equals the full stay length.
- Single-day stays where both visit on the same day: returns 1.
- Touching stays (one leaves the day the other arrives): returns 1, because both ends are inclusive.
- Adjacent but non-touching stays (e.g. 10-31 and 11-01): returns 0.
- Stays spanning month or year boundaries (e.g. 01-01 to 12-31): handled by the prefix sums, giving 365 for a full-year overlap.
- One stay entirely inside the other: returns the inner stay's length.

LLM Testcase Validation:
Test 1: arriveAlice="08-15", leaveAlice="08-18", arriveBob="08-16", leaveBob="08-19"
- Day-of-year offset for August (sum of Jan-Jul) = 31+28+31+30+31+30+31 = 212
- Alice: 227 to 230. Bob: 228 to 231
- Overlap: start = max(227, 228) = 228, end = min(230, 231) = 230
- Result = 230 - 228 + 1 = 3. Expected 3. PASS

Test 2: arriveAlice="10-01", leaveAlice="10-31", arriveBob="11-01", leaveBob="12-31"
- October offset = 273, November offset = 304, December offset = 334
- Alice: 274 to 304. Bob: 305 to 365
- Overlap: start = max(274, 305) = 305, end = min(304, 365) = 304
- end - start + 1 = 0, so max(0, 0) = 0. Expected 0. PASS
