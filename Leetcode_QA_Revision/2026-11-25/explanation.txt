Title: Smallest Unique Subarray
URL: https://leetcode.com/problems/smallest-unique-subarray/

LLM Explanation:
The property "some subarray of length L occurs exactly once" is monotonic in L. Suppose a length-L subarray at position i is unique. Extend it by one element, to the right if possible and otherwise to the left, to get a length L+1 subarray. If this longer subarray occurred at another position, its length-L part would also occur at another position, which contradicts the uniqueness of the original. So the longer one is unique too. The full array (length n) is always unique, so the answer exists in [1, n] and can be found by binary search.

To check a given L, compute a polynomial rolling hash of every window of length L using prefix hashes modulo 2^61-1 with a random base, count the hashes in a Counter, and report true if any hash has count 1. The random base and large modulus make collisions negligible.

Time complexity: O(n log n), about 17 binary search steps with O(n) each. Space complexity: O(n).

Edge cases:
- n=1 returns 1, since the single element is unique.
- An all-equal array returns n, since every shorter window repeats.
- A value that appears once in the array returns 1.
- Hash collisions are possible in theory but have probability around n^2 / 2^61, which is negligible.
