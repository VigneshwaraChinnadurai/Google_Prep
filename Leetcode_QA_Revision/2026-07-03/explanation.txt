Title: Network Recovery Pathways
URL: https://leetcode.com/problems/network-recovery-pathways/

LLM Explanation:
The problem asks for the maximum "score" of a valid path from node 0 to `n-1`, where a path's score is its minimum edge cost. This "max-min" structure strongly suggests using binary search on the answer (the score).

The core idea is to transform the optimization problem into a decision problem: "For a given score `s`, does a valid path from 0 to `n-1` exist?" A path is valid if all its intermediate nodes are online, its total cost is at most `k`, and all its edge costs are at least `s`.

We can implement a function `check(s)` to answer this question.
1.  **Subgraph Construction**: We first filter the graph to consider only paths relevant to the score `s`. This means we build a subgraph containing only online nodes and edges with a cost of `s` or more.
2.  **Shortest Path in DAG**: In this subgraph, we need to find the path from 0 to `n-1` with the minimum total cost. Since the graph is a Directed Acyclic Graph (DAG), we can do this efficiently in linear time `O(V+E)` using a topological sort-based algorithm.
    *   We compute the in-degrees of all nodes in the subgraph.
    *   Using Kahn's algorithm, we generate a topological ordering of the nodes.
    *   We then iterate through the nodes in this order, relaxing edges to find the shortest path distances from the source node 0.
3.  **Validation**: If the shortest path cost to node `n-1` is less than or equal to `k`, a valid path for score `s` exists, and `check(s)` returns `true`. Otherwise, it returns `false`.

With the `check(s)` function, we perform a binary search on the score `s` over the range of possible costs `[0, 10^9]`.
- If `check(mid)` is `true`, it means a score of `mid` is achievable. We then try for a potentially higher score by searching in the upper half `[mid + 1, high]`.
- If `check(mid)` is `false`, the score `mid` is too high. We must search in the lower half `[low, mid - 1]`.

This process continues until the search space is exhausted. The highest score for which `check(s)` returned `true` is our answer. If no valid path exists even for a score of 0, the initial answer of -1 is returned.

The overall time complexity is `O(log(C) * (N + M))`, where `C` is the maximum edge cost, `N` is the number of nodes, and `M` is the number of edges. The space complexity is `O(N + M)` for storing the graph.
