Title: Find Two Non-overlapping Sub-arrays Each With Target Sum
URL: https://leetcode.com/problems/find-two-non-overlapping-sub-arrays-each-with-target-sum/

LLM Explanation:
APPROACH: Sliding window + prefix sum with best-so-far array — O(n).

KEY OBSERVATION: Since arr[i] >= 1, we can use a prefix sum hash map to find
all subarrays ending at i with sum == target in O(1) per index.

ALGORITHM:
1. Maintain prefix_sum map: prefix_sum[s] = last index where cumulative sum = s.
2. At each index i, if curr_sum - target exists in prefix_sum, we found a subarray
   [start, i] with sum = target, length = i - start + 1.
3. best[i] = minimum length of any valid subarray ending at or before index i.
4. For each valid subarray [start, i], check if there's a non-overlapping valid
   subarray entirely before start: use best[start-1].
5. Update answer: ans = min(ans, best[start-1] + current_length).

WHY PREFIX SUM (not sliding window): All arr[i] >= 1 allows prefix sums to work
correctly (no negative values making the two-pointer approach ambiguous).

COMPLEXITY: O(n) time, O(n) space.

EDGE CASES:
  Only one valid subarray: ans stays INF, return -1.
  Valid subarray starts at index 0: can't pair with any previous subarray.
  Multiple valid subarrays: best[] ensures we track the shortest seen so far.
  Target not achievable: return -1.
