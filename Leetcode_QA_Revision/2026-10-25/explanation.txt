Title: Number of Closed Islands
URL: https://leetcode.com/problems/number-of-closed-islands/

LLM Explanation:
An island is closed only if none of its land cells lies on the grid border, since a border cell has an open side. So for each unvisited land cell, flood-fill its whole island (iterative DFS to avoid recursion limits on a 100x100 grid), mark cells visited by turning them into water on a copy of the grid, and track whether any visited cell was on the border. If no cell touched the border, increment the count.

Time complexity: O(m*n), since each cell is visited at most once. Space complexity: O(m*n) for the grid copy and the stack.

Edge cases:
- A 1xN or Nx1 grid has every cell on the border, so the answer is 0.
- An all-water grid returns 0.
- An all-land grid is one island touching the border, so it returns 0.
- Diagonal adjacency does not connect land, because only 4-directional moves are used.

LLM Testcase Validation:
Test 1 (5x8 grid): The land cells in column 7 (rows 0, 1, 2, 4) form an island touching the right border, so it is not closed. The island around rows 1-3, columns 1-4 is fully enclosed by water, so it counts. The single land cell at (3,6) is surrounded by water on all four sides and is not on the border, so it counts too. Total 2. Expected 2. PASS
Test 2 (3x5 grid): The land at (0,0), (0,1), (0,3), (0,4), (1,0), (1,2), (1,4), (2,0), (2,4) all touch the border directly or through connected land. The only land cell not on the border is (1,2), which has water on its left (1,1), right (1,3) and bottom (2,2), but its top (0,2) is water too. So (1,2) is enclosed on all four sides and is a closed island. Total 1. Expected 1. PASS
Test 3 (7x7 grid): The outer ring of land (rows/cols 1 and 5) forms one closed island enclosed by the border of water. The single cell at (3,3) is enclosed by the water ring at rows 2-4, columns 2-4, so it is a second closed island. Total 2. Expected 2. PASS
