Title: Count Subarrays With Majority Element I
URL: https://leetcode.com/problems/count-subarrays-with-majority-element-i/

LLM Explanation:
### Method Explanation

The problem asks us to count the number of subarrays where a given `target` is the majority element. An element is a majority element if it appears strictly more than half the times in the subarray.

#### 1. Simplifying the Majority Condition

The condition for `target` being a majority element in a subarray of length `L` is:
`count(target) > L / 2`

Let `k` be the count of `target` and `m` be the count of other elements in the subarray. Then `L = k + m`. The condition becomes:
`k > (k + m) / 2`
`2k > k + m`
`k > m`

This simplified condition is much easier to work with: `target` is the majority element if its count is strictly greater than the count of all other elements combined.

#### 2. Brute-Force with Optimization

A direct approach is to check every possible subarray. We can iterate through all possible start and end indices. For a subarray starting at index `i` and ending at `j`, we can count the occurrences of `target` and other elements.

To make this efficient, for a fixed starting index `i`, we can extend the subarray by moving the end index `j` from `i` to `n-1`. As we add each new element `nums[j]`, we can update the counts in O(1) time.

#### 3. Using a Balance Score

To check the condition `k > m`, we can maintain a single integer variable, let's call it `balance`, defined as `balance = k - m`. The majority condition `k > m` is then equivalent to `balance > 0`.

The `balance` score is updated as we iterate through the subarray:
- If the current element is `target`, we increment `balance`.
- If the current element is not `target`, we decrement `balance`.

#### 4. Algorithm

1.  Initialize `total_majority_subarrays` to 0.
2.  Iterate through each possible starting index `i` from `0` to `n-1`.
3.  For each `i`, initialize a `balance` score to 0.
4.  Start a nested loop for the ending index `j` from `i` to `n-1`. This loop considers all subarrays starting at `i`.
5.  In the inner loop, update the `balance` based on the element `nums[j]`.
6.  After updating, if `balance > 0`, it means `target` is the majority element in the current subarray `nums[i..j]`. Increment `total_majority_subarrays`.
7.  After both loops complete, return `total_majority_subarrays`.

This approach correctly checks all `n * (n+1) / 2` subarrays and is efficient enough for the given constraints.

### Complexity Analysis

-   **Time Complexity:** O(n²), where `n` is the length of `nums`. The nested loops iterate through all possible subarrays, and the work inside each inner loop is O(1).
-   **Space Complexity:** O(1), as we only use a few variables (`total_majority_subarrays`, `balance`, loop indices) regardless of the input size.

### Edge Cases

-   **`target` not in `nums`:** The `balance` score will always be negative for any non-empty subarray. The function correctly returns 0.
-   **All elements are `target`:** The `balance` will always be positive. The function correctly counts all `n * (n+1) / 2` subarrays.
