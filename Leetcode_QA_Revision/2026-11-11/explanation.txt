Title: Minimum Cost to Acquire Required Items
URL: https://leetcode.com/problems/minimum-cost-to-acquire-required-items/

LLM Explanation:
Let t be the number of type 3 items bought. The total cost is a function of t that is piecewise linear, so its minimum sits at a breakpoint: t = 0, t = min(need1, need2), or t = max(need1, need2).

- t = 0: buy only singles, cost1*need1 + cost2*need2.
- t = min(need1, need2): type 3 items fully cover the smaller need, and the remainder of the larger need is bought with the matching single type. If need1 <= need2 the remainder is type 2 items, otherwise type 1 items.
- t = max(need1, need2): type 3 items alone cover both needs, costing costBoth * max(need1, need2).

Between breakpoints, each extra type 3 item replaces either two singles (slope costBoth - cost1 - cost2) or one single (slope costBoth - cost of that single), and past the larger need it only adds cost. The slopes are constant on each segment, so an optimum is always at one of the three breakpoints, and taking the minimum of the three costs gives the answer.

Time complexity: O(1). Space complexity: O(1).

Edge cases:
- need1 = 0 or need2 = 0: lo = 0, so option B equals buying singles for the remaining need, and option C is never better unless costBoth is cheaper than a single.
- need1 = need2: option B equals option C.
- costBoth very large: option A wins.
- Values reach about 10^15, which Python integers handle without overflow.

LLM Testcase Validation:

Test 3: cost1=5, cost2=4, costBoth=15, need1=0, need2=0. lo=0, hi=0. A = 0, B = 0, C = 0. Min is 0. Expected 0. PASS
