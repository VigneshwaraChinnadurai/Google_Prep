Title: Maximum Score of Non-overlapping Intervals
URL: https://leetcode.com/problems/maximum-score-of-non-overlapping-intervals/

LLM Explanation:
APPROACH: DP with binary search — O(K * n log n).

Sort intervals by right endpoint (tie-break: left endpoint, then original index).
dp[k][i] = (max_weight, lex_smallest_index_tuple) picking exactly k non-overlapping
intervals from the first i intervals (in sorted order).

TRANSITION for interval i (original index idx, endpoints l_i, r_i, weight w_i):
1. Skip: dp[k][i] = dp[k][i-1]
2. Take: binary search for the last interval j with r_j < l_i (strictly non-overlapping).
   dp[k][i] = combine dp[k-1][j] with current interval.

TIE-BREAKING for lexicographically smallest: when weights are equal, compare sorted
index tuples lexicographically (smaller tuple wins).

ANSWER: Iterate k=1..4, pick the (weight, indices) with maximum weight (lex smallest on tie).

COMPLEXITY:
  Sorting: O(n log n)
  DP: O(K * n) states, O(log n) binary search per state → O(K * n log n)
  With K=4, n=5*10^4: ~2*10^6 operations.

EDGE CASES:
  Single interval: k=1 always valid.
  No valid k-interval combination for some k: dp[k][n] stays (-1, ()).
  Intervals sharing boundary are overlapping (use strict l > r check via bisect_left).
