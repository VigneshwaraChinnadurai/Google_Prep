Title: Minimum Sum of Squared Difference
URL: https://leetcode.com/problems/minimum-sum-of-squared-difference/

LLM Explanation:
APPROACH: Greedy leveling with binary search O(n log n).

Key insight: we can redistribute k1+k2 total operations to reduce any absolute difference
by 1 per operation. To minimise sum of squares, always reduce the largest differences first
(since reducing a large value saves more than reducing a small one: d²-(d-1)² = 2d-1).

ALGORITHM:
1. Compute absolute differences, sort descending.
2. For each "level" i (flattening diffs[0..i] to diffs[i+1]):
   - Cost = (diffs[i] - diffs[i+1]) * (i+1) operations to level top i+1 values.
   - If k >= cost: apply, continue to next level.
   - Else: distribute remaining k evenly (quotient across all, remainder to highest).

This processes at most n levels and each level is O(n) assignment → O(n²) worst case.
With n≤10^5 this could be slow; but in practice early exit via k=0 keeps it fast.
For guaranteed O(n log n): binary search for the cutoff level first, then apply in O(n).

COMPLEXITY: O(n log n) for sort, O(n) for greedy pass.

EDGE CASES:
  k=0: return sum of diffs² immediately.
  k large enough to zero all diffs: return 0.
  Equal diffs: leveling costs 0 steps, continues freely.
