Title: Maximum Number of Non-overlapping Palindrome Substrings
URL: https://leetcode.com/problems/maximum-number-of-non-overlapping-palindrome-substrings/

LLM Explanation:
APPROACH: Palindrome DP precomputation + greedy interval DP — O(n^2).

STEP 1: Precompute is_pal[i][j] for all substrings in O(n^2).

STEP 2: Greedy DP where dp[i] = max non-overlapping palindromes in s[0..i-1].
  dp[i] = dp[i-1]  (skip position i-1)
  For each palindrome s[j..i-1] of length >= k:
    dp[i] = max(dp[i], dp[j] + 1)

GREEDY BREAK: For maximum count, we want as many short palindromes as possible
(greedy: take the shortest valid palindrome ending at position i-1).
We iterate j from i-k down to 0 and BREAK at the first valid palindrome found.
This gives us the rightmost-starting (shortest) palindrome ending here, maximizing
future opportunities.

WHY GREEDY BREAK IS CORRECT: Taking a shorter palindrome ending at i-1 uses fewer
characters, leaving more room for future palindromes. This is a classical greedy
argument for interval scheduling.

COMPLEXITY:
  Precomputation: O(n^2) time and space.
  DP: O(n^2) transitions.
  Total: O(n^2) time, O(n^2) space.

EDGE CASES:
  k > n: no palindrome of length >= k possible → return 0.
  k = 1: every single character is a palindrome, answer = n.
  No palindrome of length >= k: return 0.

LLM Testcase Validation:
Test 1: s="abaccdbbd", k=3, n=9
is_pal precomputed for all substrings.

Key palindromes of length>=3:
- s[0..2]="aba" ✓
- s[2..5]="acca"? s="abaccdbbd", s[2]='a',s[3]='c',s[4]='c',s[5]='d'→"accd" not palindrome.
  Actually s="abaccdbbd": a,b,a,c,c,d,b,b,d
- s[0..2]="aba" ✓ (len=3)
- s[2..4]="acc" not palindrome
- s[3..4]="cc" len=2 < k=3
- s[5..8]="dbbd" ✓ (len=4)
- s[6..7]="bb" len=2 < k=3

dp[0]=0
dp[1]=0 (no palindrome of len>=3 ending at 0)
dp[2]=0
dp[3]: j=0, s[0..2]="aba" is_pal=True → dp[3]=max(dp[2], dp[0]+1)=max(0,1)=1. Break.
dp[4]: j=1, s[1..3]="bac" not pal; j=0, s[0..3]="abac" not pal. dp[4]=dp[3]=1.
dp[5]: j=2, s[2..4]="acc" no; j=1, "bacc" no; j=0, "abacc" no. dp[5]=1.
dp[6]: j=3, s[3..5]="ccd" no; j=2, "accd" no; j=1, "baccd" no; j=0, "abaccd" no. dp[6]=1.
dp[7]: j=4, s[4..6]="cdb" no; j=3, "ccdb" no; ... dp[7]=1.
dp[8]: j=5, s[5..7]="dbb" no; j=4, "cdbb" no; j=3, "ccdbb" no; ... 
  Actually s[5..7]="dbb"? s[5]='d',s[6]='b',s[7]='b' → "dbb" not pal.
  s[5..8]? that's len=4, j would need to be at dp position where i=9 not 8.
dp[8]=1.
dp[9]: j=6, s[6..8]="bbd"? s[6]='b',s[7]='b',s[8]='d'→"bbd" not pal.
  j=5, s[5..8]="dbbd", s[5]='d',s[8]='d',is_pal[6][7]=True(s[6]='b'=s[7]) → "dbbd" is pal ✓.
  dp[9]=max(dp[8], dp[5]+1)=max(1, 1+1)=2. Break.
Return dp[9]=2 ✓
