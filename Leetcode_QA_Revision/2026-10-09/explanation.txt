Title: Minimum Insertions to Balance a Parentheses String
URL: https://leetcode.com/problems/minimum-insertions-to-balance-a-parentheses-string/

LLM Explanation:
APPROACH: Greedy one-pass — O(n).

Track `open_count` = unmatched '(' that need '))' to close.

For each character:
- '(': increment open_count.
- ')': try to consume '))' (look at next char). If next is not ')', insert one ')' (insertions++). Then try to match with an open '(': if open_count > 0 decrement it, else insert a '(' (insertions++).

At the end, each remaining open_count needs 2 ')' each → insertions += 2 * open_count.

COMPLEXITY: O(n) time, O(1) space.

EDGE CASES:
  All ')': each pair needs a '(' inserted. Odd ')' also needs both a '(' and one ')'.
  All '(': each needs '))' → 2 * n insertions.
  Consecutive '))': consumed as one closing unit.
