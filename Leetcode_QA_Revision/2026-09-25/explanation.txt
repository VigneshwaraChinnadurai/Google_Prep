Title: Brace Expansion II
URL: https://leetcode.com/problems/brace-expansion-ii/

LLM Explanation:
APPROACH: Recursive descent parser — O(n * 2^n) worst case, O(n) in practice.

GRAMMAR:
  expression = group (group)*
  group = letter | '{' expression (',' expression)* '}'

PARSING RULES:
  - Letter: extend every string in the current concatenation group.
  - '{...}': recursively parse inner, then cross-product with current group.
  - ',': union the current group into result, start a fresh concatenation group.
  - '}': signals end of inner expression, return to caller.

Each call to parse() handles one level of braces, returning the set of words and
the index after the closing '}' (or end of string for the outermost level).

WHY SETS: Handles deduplication automatically (union, cartesian product uses sets).

COMPLEXITY:
  Parsing: O(n) character traversal.
  Set operations: cross-products can expand exponentially but expression length ≤ 60
  bounds the total output size practically.
  Sorting: O(W log W) where W = number of distinct words.

EDGE CASES:
  Nested braces: handled by recursive calls.
  Consecutive groups (implicit concatenation): cross-product applied each time a
  new group (letter or braced) is encountered.
  Duplicate words: set union deduplicates automatically.
