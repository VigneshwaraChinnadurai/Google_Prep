Title: Circle and Rectangle Overlapping
URL: https://leetcode.com/problems/circle-and-rectangle-overlapping/

LLM Explanation:
Find the point on (or inside) the rectangle closest to the circle center by clamping
the center coordinates to the rectangle bounds. If the squared distance from the
center to this closest point is <= radius², they overlap (share at least one point).

O(1) time and space. Handles all cases: center inside rectangle (dist=0), tangent,
and fully separate.

LLM Testcase Validation:
Test 1: radius=1, center=(0,0), rect=[1,-1,3,1]
closest_x=max(1,min(0,3))=max(1,0)=1, closest_y=max(-1,min(0,1))=0
dx=0-1=-1, dy=0-0=0. dist²=1<=1 → True ✓

Test 2: radius=1, center=(1,1), rect=[1,-3,2,-1]
closest_x=max(1,min(1,2))=1, closest_y=max(-3,min(1,-1))=max(-3,-1)=-1
dx=1-1=0, dy=1-(-1)=2. dist²=4>1 → False ✓

Test 3: radius=1, center=(0,0), rect=[-1,0,0,1]
closest_x=max(-1,min(0,0))=0, closest_y=max(0,min(0,1))=0
dx=0, dy=0. dist²=0<=1 → True ✓
