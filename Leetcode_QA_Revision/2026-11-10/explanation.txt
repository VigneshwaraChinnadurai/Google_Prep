Title: Climbing Stairs II
URL: https://leetcode.com/problems/climbing-stairs-ii/

LLM Explanation:
Let dp[j] be the minimum total cost to reach step j, with dp[0] = 0. A jump into step j comes from step j-1, j-2, or j-3, and a jump of length d adds costs[j] + d^2. So dp[j] = costs[j] + min over d in {1,2,3} of (dp[j-d] + d^2), considering only j-d >= 0. The costs array is 1-indexed in the statement, so costs[j] in the statement is costs[j-1] in the 0-indexed Python list. The answer is dp[n].

Time complexity: O(n), since each step checks at most 3 predecessors. Space complexity: O(n) for the dp array, which could be reduced to O(1) by keeping only the last three values.

Edge cases:
- n=1: only the jump 0 -> 1 exists, so the answer is costs[1] + 1.
- n=2: only jumps of length 1 or 2 from the valid earlier steps are considered, since predecessors below 0 are skipped.
- Large n (up to 10^5): the loop is linear and the values stay well within Python integer range.

LLM Testcase Validation:
