Title: Minimum Moves to Equal Array Elements III
URL: https://leetcode.com/problems/minimum-moves-to-equal-array-elements-iii/

LLM Explanation:
Moves can only increase an element, so the final common value can never be below the current maximum. Raising the target above the maximum only adds extra moves for every element, so the best target is exactly max(nums). Each element x then needs max - x increments, and the total is the sum of (max - x), which equals max * n - sum.

Time complexity: O(n). Space complexity: O(1).

Edge cases:
- n=1 returns 0.
- All elements equal returns 0.
- Constraints are small (n <= 100, values <= 100), so there is no overflow concern.

LLM Testcase Validation:
[2,1,3]: max = 3, n = 3, sum = 6, so 3*3 - 6 = 3. Expected 3. PASS
[4,4,5]: max = 5, n = 3, sum = 13, so 5*3 - 13 = 2. Expected 2. PASS
