Title: Maximum Ice Cream Bars

LLM Explanation:
### Method: Greedy with Counting Sort

The problem asks for the maximum number of ice cream bars we can buy with a given amount of coins. To maximize the number of items purchased within a fixed budget, a greedy approach is optimal: always buy the cheapest available item first. This ensures that we spend as little as possible on each item, leaving more money for future purchases.

The problem explicitly requires using counting sort. This is a hint that the range of costs is limited, which is confirmed by the constraints (`1 <= costs[i] <= 10^5`). Counting sort is an ideal choice here because it can effectively sort or group the costs in linear time, which is more efficient than a comparison-based sort like quicksort or mergesort (O(n log n)).

The algorithm proceeds as follows:

1.  **Frequency Counting:** We first create a frequency array, `freq`, to store the count of ice cream bars for each distinct price. Since the maximum cost is 100,000, this array will have a size of 100,001. We iterate through the input `costs` list once to populate this frequency array. This step takes O(n) time, where n is the number of ice cream bars.

2.  **Greedy Purchase Simulation:** We then iterate through the possible costs from the smallest (1) to the largest (100,000). This is equivalent to iterating through the ice cream bars in sorted order of their cost. For each `cost`:
    *   We check if we have enough `coins` to buy at least one bar at the current `cost`. If not (`coins < cost`), we can't afford this bar or any more expensive ones, so we can break the loop.
    *   If we can afford it and there are bars available at this price (`freq[cost] > 0`), we calculate the maximum number of bars we can buy. This is the minimum of the number of bars available (`freq[cost]`) and the number we can afford (`coins // cost`).
    *   We add this number to our total `ice_cream_count` and subtract the total expenditure from our `coins`.

3.  **Return Result:** After the loop terminates, `ice_cream_count` holds the maximum number of ice cream bars that can be bought.

### Complexity Analysis

*   **Time Complexity:** O(n + m), where `n` is the number of ice cream bars and `m` is the maximum possible cost (100,000 in this case). O(n) is for populating the frequency array, and O(m) is for iterating through the possible costs. Given the constraints, this is a linear time solution.
*   **Space Complexity:** O(m) to store the frequency array. Since `m` is a constant based on the problem constraints (100,001), this can be considered O(1) or constant space relative to the input size `n`.
