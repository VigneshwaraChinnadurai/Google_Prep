Title: Process String with Special Operations I
URL: https://leetcode.com/problems/process-string-with-special-operations-i/

LLM Explanation:
The problem requires us to simulate a string processing procedure based on a set of rules for special characters. A direct, step-by-step simulation is the most straightforward approach.

### Data Structure Choice
To build the `result` string, we can use a mutable sequence like a Python `list` of characters. This is more efficient than using an immutable `str` object, especially for operations like appending or removing the last character. Modifying a list in-place avoids the overhead of creating a new string object for each change.

### Algorithm
1.  Initialize an empty list, `res_list`, to store the characters of our resulting string.
2.  Iterate through each character `char` of the input string `s` from left to right.
3.  For each `char`, apply the corresponding rule:
    - If `char` is a lowercase English letter, append it to `res_list`.
    - If `char` is `'*'`, check if `res_list` is not empty. If it's not, remove its last element using `pop()`.
    - If `char` is `'#`, duplicate the current content of `res_list` by extending it with a copy of itself (`res_list.extend(res_list)`).
    - If `char` is `'%'`, reverse the order of elements in `res_list` in-place using `res_list.reverse()`.
4.  After iterating through all characters in `s`, join the elements of `res_list` to form the final result string.

### Example Walkthrough (`s = "a#b%*"`)
- **Initial:** `res_list = []`
- **'a'**: Append 'a'. `res_list` is `['a']`.
- **'#'**: Duplicate. `res_list` is `['a', 'a']`.
- **'b'**: Append 'b'. `res_list` is `['a', 'a', 'b']`.
- **'%'**: Reverse. `res_list` is `['b', 'a', 'a']`.
- **'*'**: Remove last. `res_list` is `['b', 'a']`.
- **Final**: Join the list: `"ba"`.

### Complexity Analysis
- **Time Complexity:** O(N + M_total), where N is the length of the input string `s`, and M_total is the sum of the lengths of the `res_list` during all operations that scale with its size (`#` and `%`). In the worst-case scenario (e.g., many `'#'` operations), the final length of the result can be exponential with respect to N. The complexity is dominated by the cost of manipulating this potentially long list.
- **Space Complexity:** O(M), where M is the maximum length achieved by `res_list`. This is to store the characters of the result string.
