Title: Sequential Digits

LLM Explanation:
### Method Explanation

The core idea is to recognize that the set of all integers with sequential digits is very small and can be generated systematically. Every such number is a substring of the master string "123456789". For example, 234 is ` "123456789"[1:4] ` and 5678 is ` "123456789"[4:8] `.

The algorithm leverages this property to efficiently find all sequential numbers within the given `[low, high]` range:

1.  **Constrain Search Space by Length**: Any valid number `x` in the range `[low, high]` must have a number of digits between `len(str(low))` and `len(str(high))`. We can iterate through this range of possible lengths.

2.  **Generate Candidates**: For each possible `length`, we use a sliding window approach on the `sample` string "123456789" to generate all sequential numbers of that length. For a length of 3, this would generate 123, 234, 345, and so on.

3.  **Filter and Collect**: As each number is generated, we check if it falls within the `[low, high]` range.
    - If `num >= low` (and `num <= high`), we add it to our result list.
    - The numbers are generated in a naturally sorted order (e.g., 12, 23, ..., 89, 123, 234, ...). This allows for a crucial optimization: if a generated number `num` exceeds `high`, we know all subsequent numbers will also be larger. Thus, we can immediately stop the generation process and return the results found so far.

This approach is highly efficient because it avoids checking every number in the `[low, high]` range. Instead, it directly generates the only possible candidates and filters them.

### Complexity Analysis

-   **Time Complexity**: `O(1)`. The total number of sequential digit integers is constant and small (36 numbers from length 2 to 9). The nested loops run a fixed number of times, regardless of the size of the `low` and `high` inputs.
-   **Space Complexity**: `O(1)`. The space required for the result list is bounded by the constant number of sequential digits.
