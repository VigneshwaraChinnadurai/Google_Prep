Title: Smallest Stable Index I
URL: https://leetcode.com/problems/smallest-stable-index-i/

LLM Explanation:
APPROACH: Prefix max + suffix min precomputation — O(n).

Precompute prefix_max[i] = max(nums[0..i]) and suffix_min[i] = min(nums[i..n-1]) in two
linear passes. Then scan left to right and return the first i where
prefix_max[i] - suffix_min[i] <= k.

COMPLEXITY: O(n) time, O(n) space.

EDGE CASES:
  n=1: single element, instability = nums[0] - nums[0] = 0.
  All same values: instability always 0.
  k=0: need prefix_max[i] == suffix_min[i], meaning all elements so far equal all remaining.

LLM Testcase Validation:
Test 1: nums=[5,0,1,4], k=3
prefix_max=[5,5,5,5], suffix_min=[0,0,1,4]
i=0: 5-0=5>3
i=1: 5-0=5>3
i=2: 5-1=4>3
i=3: 5-4=1<=3 → return 3 ✓

Test 2: nums=[3,2,1], k=1
prefix_max=[3,3,3], suffix_min=[1,1,1]
i=0: 3-1=2>1
i=1: 3-1=2>1
i=2: 3-1=2>1
return -1 ✓

Test 3: nums=[0], k=0
prefix_max=[0], suffix_min=[0]
i=0: 0-0=0<=0 → return 0 ✓
