Title: Shortest and Lexicographically Smallest Beautiful String
URL: https://leetcode.com/problems/shortest-and-lexicographically-smallest-beautiful-string/

LLM Explanation:
APPROACH: Brute force with early termination — O(n^2).

For each starting index i, expand right until exactly k ones are accumulated.
The first j where ones==k gives the shortest beautiful substring starting at i
(adding more characters would only increase length without reducing ones count
to below k — we'd need to shrink from the left, which is handled by i+1).

Track the global best by: shortest length first, then lexicographically smallest
among ties.

Since n ≤ 100, O(n^2) = 10,000 operations is trivially fast.

EDGE CASES:
  No 1s in s or total ones < k: best stays "" → return "".
  k ones found at exactly the last position: handled by the inner j loop.
  Multiple substrings of same minimum length: lexicographic comparison picks smallest.
