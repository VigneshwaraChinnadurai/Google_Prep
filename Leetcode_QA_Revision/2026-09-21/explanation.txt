Title: Find X Value of Array I
URL: https://leetcode.com/problems/find-x-value-of-array-i/

LLM Explanation:
APPROACH: Sliding DP on subarrays — O(n * k) time, O(k) space.

For each right endpoint j, maintain cnt[r] = number of subarrays ending at j
with product ≡ r (mod k).

TRANSITION: When processing nums[j]:
  For each existing subarray ending at j-1 with remainder r:
    It extends to a subarray ending at j with remainder (r * nums[j]) % k.
  Plus the new single-element subarray [nums[j]] with remainder nums[j] % k.

Accumulate cnt into result[r] after each j.

CORRECTNESS: Every contiguous subarray nums[i..j] is counted exactly once,
when j is processed.

COMPLEXITY:
  Time: O(n * k), with n up to 10^5 and k up to 5 → at most 5*10^5 ops.
  Space: O(k) = O(5).

EDGE CASES:
  k=1: all products ≡ 0 mod 1, result[0] = n*(n+1)/2.
  Large nums[i]: only nums[i] % k matters for the transition.
  Single element: one subarray contributing nums[0] % k.
