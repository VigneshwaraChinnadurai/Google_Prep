Title: Minimum Swaps to Sort by Digit Sum
URL: https://leetcode.com/problems/minimum-swaps-to-sort-by-digit-sum/

LLM Explanation:
Minimum swaps to sort = number of swaps in cycle decomposition of the permutation.
Each cycle of length k needs k-1 swaps. Build target sorted array, map values to
target positions, then count cycles. O(n log n) time, O(n) space.

LLM Testcase Validation:
Test 1: nums=[37,100]. target=[100,37]. pos={100:0,37:1}.
i=0: nums[0]=37≠target[0]=100. j=0→pos[37]=1→pos[100]=0(visited). cycle=2. swaps=1.
Return 1 ✓

Test 2: nums=[22,14,33,7]. digit_sums=[4,5,6,7]. target=[22,14,33,7]=nums. swaps=0 ✓

Test 3: nums=[18,43,34,16]. digit_sums=[9,7,7,7]. target sorted by (ds,val): (7,16),(7,34),(7,43),(9,18)=[16,34,43,18].
pos={16:0,34:1,43:2,18:3}.
i=0: nums[0]=18≠16. j=0→pos[18]=3→pos[16]=0(visited). cycle=2. swaps=1.
i=1: nums[1]=43≠34. j=1→pos[43]=2→pos[34]=1(visited). cycle=2. swaps=2.
i=2: visited. i=3: visited.
Return 2 ✓
