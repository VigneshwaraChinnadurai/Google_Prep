Title: Find the Distance Value Between Two Arrays
URL: https://leetcode.com/problems/find-the-distance-value-between-two-arrays/

LLM Explanation:
An element a of arr1 fails the condition if any element of arr2 lies within distance d, and the only candidates that need checking are the nearest elements of arr2 on each side of a. Sort arr2, use bisect_left to find the first element >= a, and check that element and its predecessor. If neither is within d, a counts toward the distance value.

Time complexity: O((n + m) log m), covering the sort of arr2 and one binary search per element of arr1. Space complexity: O(m) for the sorted copy. With the given limits (at most 500 elements each), a brute-force O(n*m) check would also pass, but this is faster.

Edge cases:
- d=0 means only exact matches disqualify an element.
- An element of arr1 smaller than everything in arr2 has no predecessor, which is handled by the i > 0 check.
- An element larger than everything in arr2 has no successor, which is handled by the i < m check.
- Duplicates in either array are fine, since each arr1 element is judged independently.
