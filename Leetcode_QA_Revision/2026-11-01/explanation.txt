Title: Minimum Moves to Equal Array Elements
URL: https://leetcode.com/problems/minimum-moves-to-equal-array-elements/

LLM Explanation:
Incrementing n-1 elements by 1 changes the gap between the incremented elements and the one left out by exactly the same amount as decrementing that one element by 1 would, once all values are compared relative to each other. So the problem is equivalent to: in one move, decrease a single element by 1, and find the fewest moves to make all elements equal.

The cheapest target is the minimum value, because lowering anything below the minimum only adds moves. Each element x needs x - min decrements, so the total is the sum of (x - min) over all elements, which equals sum(nums) - min(nums) * n.

Time complexity: O(n). Space complexity: O(1).

Edge cases:
- n=1 returns 0.
- All elements equal returns 0.
- Negative values work unchanged, since only differences from the minimum matter.
- Python integers do not overflow, and the answer is guaranteed to fit in 32 bits anyway.

LLM Testcase Validation:
[1,2,3]: sum = 6, min = 1, n = 3, so 6 - 1*3 = 3. Expected 3. PASS
[1,1,1]: sum = 3, min = 1, n = 3, so 3 - 3 = 0. Expected 0. PASS
