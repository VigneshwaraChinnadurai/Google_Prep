Title: Maximum Number of Non-Overlapping Substrings
URL: https://leetcode.com/problems/maximum-number-of-non-overlapping-substrings/

LLM Explanation:
APPROACH: Greedy interval selection — O(n * 26) = O(n).

KEY INSIGHT: A valid substring starting at i must contain ALL occurrences of every
character it contains. So we expand the right boundary greedily: starting from
last[s[i]], include every character encountered, extending right as needed.

A starting position i is only valid if first[s[i]] == i (i must be the first
occurrence of its character, otherwise any valid substring covering s[i] must
start earlier).

ALGORITHM:
1. For each valid starting i (first occurrence of s[i]), compute the minimal
   right boundary r via get_right(i). If any enclosed character has its first
   occurrence before i, the substring is invalid (return -1).

2. Greedy scan left to right:
   - If i > last_end: start a new substring [i, r], update last_end = r.
   - Else (i overlaps with current last substring): if r < last_end, this
     shorter substring replaces the current one (same count, smaller length).

WHY GREEDY WORKS: We want maximum count with minimum total length. The greedy
approach processes potential substrings in order of their start, always trying
to shrink the current rightmost endpoint (to leave room for more substrings).

COMPLEXITY:
  get_right(i): O(n) per call worst case, but amortised O(1) since each char
  is visited at most twice across all calls → O(n) total.
  Overall: O(n) time, O(26) = O(1) space (ignoring output).
