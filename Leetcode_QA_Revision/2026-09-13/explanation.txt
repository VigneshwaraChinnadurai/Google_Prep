Title: Image Overlap
URL: https://leetcode.com/problems/image-overlap/

LLM Explanation:
APPROACH: Translation vector counting — O(n^4) worst case, O(A*B) in practice.

For img1 translated by vector (dr, dc) to overlap img2, a 1-cell (r1,c1) in img1
overlaps a 1-cell (r2,c2) in img2 iff (r2-r1, c2-c1) == (dr, dc).

So for each pair of 1-cells (one from each image), compute their translation vector.
The most common translation vector gives the maximum overlap.

COMPLEXITY:
  A = number of 1s in img1, B = number of 1s in img2 (each <= n^2 = 900).
  Time: O(A * B) <= O(n^4) = O(810000) for n=30. Fast.
  Space: O(A * B) for the count map.

EDGE CASES:
  No 1s in either image: return 0.
  All 0s: return 0.
  Single cell: straightforward.
  Best overlap at (0,0) translation (no shift needed): handled naturally.
