Title: Twisted Mirror Path Count
URL: https://leetcode.com/problems/twisted-mirror-path-count/

LLM Explanation:
Let dp[i][j] be the number of ways the robot lands on the non-mirror cell (i,j). Mirror cells have dp 0, since the robot never stays on one. A non-mirror cell (i,j) can be reached in four ways:

- Directly from the left, dp[i][j-1].
- Directly from above, dp[i-1][j].
- By moving right into a mirror and being pushed down a column of consecutive mirrors that ends just above (i,j). If the run of L mirrors directly above (i,j) is in column j, the robot could have started from any cell (a, j-1) in those L rows, so we add the sum of dp[a][j-1] for a from i-L to i-1.
- By moving down into a mirror and being pushed right along a row of L' consecutive mirrors that ends just left of (i,j). We add the sum of dp[i-1][b] for b from j-L' to j-1.

The two sums use column prefix sums and row prefix sums of dp, so each cell is computed in O(1). A reflection that leaves the grid has no non-mirror landing cell, so it adds nothing.

Time complexity: O(m*n). Space complexity: O(m*n).

Edge cases:
- Reflections that leave the grid are dropped naturally, because there is no landing cell to receive them.
- Chains of consecutive mirrors are handled by the run lengths L and L'.
- Start and end cells are guaranteed to be 0, so dp[0][0]=1 is valid and the answer is dp[m-1][n-1].
- Results are reduced modulo 10^9+7, and prefix-sum differences are normalized by the final modulo.
